# letter-writer

## 前提
`03_preframe.md`、`04_audience.md`、`07_objections.md` を読む。

## 手順
1. レターの型を2〜3案提示して選んでもらう(例: 共感→問題提起→解決策提示→実績→目次→CTA / ストーリー型 / 結論先出し型)。
2. 選んだ型の各要素ごとに、訴求する題材(使うエピソード・数字・N1のセリフ・反論への返答)を割り当てる。
3. 本文はまだ書かない。content-writerが書くための設計図を作る。
