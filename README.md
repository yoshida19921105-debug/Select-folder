# ここだけは覚えて｜権限モードの話

初心者が事故るとしたらここです。

権限モードは「Claudeがどこまで勝手にやっていいか」の設定です。

最初は **Manual** からでいいです。毎回止まるのは正直めんどくさいんだけど、「何をされてるか」が見えるので、慣れるまではここ。

慣れてきたらこの流れがおすすめです。

1. **Plan** で計画を出させる
2. 中身を確認する
3. **Accept edits** に切り替えて実行する

いきなり書かせるより、先に「何をするつもりか」を言わせた方が事故らないです。

**Bypass permissions** は、意味が分かるまで触らなくていいです！
