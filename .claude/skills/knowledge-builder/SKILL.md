# knowledge-builder

## 前提
`05_outline.md` を読む。

## 手順
1. 章ごとに必要な根拠を洗い出す(実績・体験談・数字・事例・一般知識)。
2. 独自の情報(実績・体験・ノウハウ・失敗談・数字)は **ユーザーにヒアリング** して引き出す。AIが捏造しない。
3. 一般知識・統計・事例は WebSearch で収集し、出典URLと取得日を付ける。確認できないものは載せない。
4. 章ごとに「主張 / 根拠 / 出典or体験 / 使いどころ」の表にまとめる。
5. 情報が足りない章は明示して追加ヒアリングを依頼する(薄い本文を防ぐ)。

## 出力: `note-project/06_knowledge.md`
