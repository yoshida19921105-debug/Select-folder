# lead-post-listup

## 前提
`04_audience.md`, `08_letter-plan.md`, `13_launch-plan.md` を読む。

## 手順
1. **教育投稿**(必要性を伝える): 読者の悩み・失敗パターン・常識の誤り・小さなノウハウから、30案以上。
2. **誘導投稿**(noteへ送る): 本文の一部の予告、ビフォーアフター、反論への答え、制作裏話から、20案以上。
3. 各案に「狙い / 投稿の骨子(1〜3行) / 投稿時期(launch-planner対応) / CTA有無」を付ける。
4. `09_style.md` の文体で書く。誇張や根拠のない数字は使わない。

## 出力: `note-project/14_lead-posts.md`
