# outline-builder

## 前提
`03_preframe.md` と `04_audience.md` を読む。

## 手順
1. 読者の問いを出てくる順に並べる(「なぜ?→どうやって?→本当に?→自分でもできる?」)。
2. 章(1,2,3…)→節(1-1,1-2…)の階層で組む。各節に「この節が答える読者の問い」と「要点1行」を付ける。
3. 導入(無料部分)・本編・おわりにを含める。図解を入れる箇所に [図解] を印付けする。
4. 有料級になるチェック: 各章に具体例/手順/テンプレのいずれかがあるか、章間の飛躍が無いか。
5. ユーザーに構成を見せ、承認を得てから確定する。
