# reader-critic

## 手順
1. `10_draft/` を対象に、Agentツールで3つのサブエージェントを並列起動する。人格例:
   - A: 初心者(専門用語・前提の飛躍で詰まる)
   - B: 懐疑的な経験者(根拠・再現性・ツッコミを突く)
   - C: 忙しい読者(冗長・退屈・離脱ポイントを突く)
   各人格には `04_audience.md` と本文だけを渡し、批評だけをさせる。
2. 各人格は章ごとに「分からない/つまらない/信じられない」箇所と理由、満足度(1〜5)を返す。
3. 指摘を統合し、content-writer の方針に沿って修正する。事実や体験は勝手に足さない(足りなければユーザーに聞く)。
4. 全員が満足度4以上になるまで繰り返す(最大3周。超えたらユーザーに判断を仰ぐ)。

## 出力: `note-project/12_critic-log.md`(周回ごとの指摘と対応)
