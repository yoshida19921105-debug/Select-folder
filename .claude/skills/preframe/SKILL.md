# preframe

## 前提
`02_topic.md` を読む。

## 決めること
1. ターゲット: 誰の、どんな現状か
2. 解決する課題と、到達点(Before→After)
3. 商品の型(ノウハウ型/事例型/テンプレ型/ロードマップ型など)
4. 基本情報: タイトル案、価格、想定文字数、図解枚数、納品形式
5. 商品概要(3〜5行)
6. コンセプト(1文)と、やらないことリスト

## ルール
曖昧な項目はユーザーに質問して確定させる。以降の全スキルはこのファイルを正とする。
