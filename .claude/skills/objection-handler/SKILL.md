# objection-handler

## 前提
`05_outline.md`、`06_knowledge.md`、`04_audience.md` を読む。

## 手順
1. 章ごとに、読者が入れそうなツッコミ(「それは〇〇だからできるのでは」「本当に再現できる?」)を2〜3個挙げる。
2. 各ツッコミに、根拠付きの返答案を書く(knowledge-builderの素材を使う)。
3. 購入前の疑問(対象者・前提知識・返金・読了時間・他商品との違い)をFAQにする。
4. 本文に織り込む先回り反論と、FAQ/無料部分に置くものを振り分ける。

## 出力: `note-project/07_objections.md`
