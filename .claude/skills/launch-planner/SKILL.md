# launch-planner

## 前提
`03_preframe.md` を読む。

## ヒアリング
販売開始希望日、執筆の完成目安、使えるSNSとフォロワー規模、告知にかけられる時間。

## 手順
1. 逆算カレンダーを作る: ティザー告知 → 教育期間 → 先行/初日 → 販売期間 → 締切。
2. 導線を決める(SNS→無料部分→有料、プロフィール・固定投稿・メンバーシップ等)。
3. 段階的値上げ計画(価格、切り替え日/部数、告知文の方針)。
4. 日ごとのタスク表と、結果を見て調整する指標(クリック・購入数)。
5. 誇大表現や根拠のない実績の訴求は入れない。
