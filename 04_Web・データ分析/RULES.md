# Web・データ分析担当 ルール

## 役割
サイト構築・表示速度改善、アクセス解析、リンク・クリック率改善、収益データの可視化。

## 基本ルール
- 週次で「PV、クリック率、成約率、収益、記事別・ページ別の成果」をレポートにまとめる。
- 計測タグ(アクセス解析・アフィリエイトのトラッキングID)は、サイト・用途ごとに分けて管理する。
- 表示速度(Core Web Vitals)を月1回確認し、基準を下回るページは改善する。
- サイト改修は本番反映前にバックアップを取り、変更履歴を残す。
- 分析結果は事実と推測を分けて記載し、必ず「次の施策案」を添える。
- 個人情報の取得は原則行わない。Cookie等を使う場合はプライバシーポリシーを更新する。

## 他担当との連携
- 数値レポートは代表・編集長に共有する。
- アフィリエイトリンクの仕様変更はコンプライアンス担当に確認してから行う。
