# topic-builder

## 前提
`note-project/01_competitor-research.md` を読む。無ければ先に competitor-research を提案する。

## 手順
1. 読者が最終的に達成したいゴールを1文で定義する(ヒアリングで確認)。
2. ゴールから逆算し、必要な「領域」→「行動」に分解する(ツリー化)。
3. 競合の売れ筋とマッピングし、被せる部分と差別化する部分を決める。
4. メインテーマ候補を3案、トピッククラスター(関連トピック群)を整理する。
5. 「有料noteにするならこれ」という推奨を1つ、理由付きで示す。他は無料発信/次回作に回す。

## 出力: `note-project/02_topic.md`
- ゴール / 逆算ツリー / メインテーマ / トピッククラスター / 推奨有料note案と理由
