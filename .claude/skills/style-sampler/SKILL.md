# style-sampler

## 手順
1. ユーザーの過去の投稿・note・文章サンプルがあれば提供してもらい、語尾・リズム・口ぐせ・改行の癖を分析する。**あれば最優先**。
2. 無い/不足なら、同じ短い題材(150〜250字)を4〜5種の文体で書く(例: 話し言葉の語りかけ/丁寧で端的/熱量高め/淡々と論理的/ゆるく親しみやすい)。
3. ユーザーに選んでもらい、混ぜたい要素や避けたい表現を聞く。
4. 確定した文体ルール(語尾、一人称、禁止表現、改行・段落の癖、サンプル文)を書き出す。

## 方針
AIらしい無機質さを避けるため、ユーザー自身の少し粗い文章の癖を意図的に残す。きれいに整えすぎない。
