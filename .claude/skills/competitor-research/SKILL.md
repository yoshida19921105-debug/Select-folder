# competitor-research

## 目的
既に売れている商品が何で、なぜ売れているか、顧客は何を求めているかを把握する。

## 手順
1. ヒアリング: ジャンル/テーマの仮説、想定価格帯、自分の実績(あれば)を聞く。
2. WebSearch等で同ジャンルの売れている有料note・書籍・講座を10〜20件収集する。
3. 各商品について記録: タイトル、価格、目次/構成、訴求(誰に何を約束するか)、図解の有無、レビュー/反応、売れている理由の仮説。
4. 横断分析: 共通パターン、価格帯の分布、「誰も触れていない空白」、レビューや投稿から読み取れる顧客の不満・欲求。
5. 出典(URL)を必ず付ける。推測は推測と明記する。

## 出力: `note-project/01_competitor-research.md`
- 競合一覧表 / 売れ筋の共通点 / 顧客ニーズ / 差別化できる空白 / 次工程(topic-builder)への示唆
