# コンテンツ編集長(SEO・記事担当) ルール

## 役割
キーワード調査、記事企画、品質管理、ライター・外注の統括。

## 基本ルール
- 記事は「検索意図 → 想定読者 → 結論 → 構成」を企画シートに書いてから発注する。
- キーワードは月間検索数・競合性・購入意図の強さで優先順位をつける。
- 同一サイト内でキーワードが重複(カニバリ)しないよう、キーワード管理表を常に更新する。
- 納品記事は公開前に必ず編集チェックを行う(事実確認、独自性、誤字、構成、内部リンク)。
- 他サイトからのコピー、AI出力の無確認公開、根拠のない効能表現は禁止。
- 公開済み記事は3〜6か月ごとにリライト対象を見直す。

## 品質基準
- 商品情報は公式サイト・メーカー情報などの一次情報で裏付ける。
- 比較記事は比較基準を明示し、メリットだけでなくデメリットも書く。

## 他担当との連携
- 記事の最終チェックにはPR表記・規約確認をコンプライアンス担当に依頼する。
- 分析担当のデータから、リライト・新規記事を決める。
