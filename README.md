# ここだけは覚えて｜権限モードの話

初心者が事故るとしたらここです。

権限モードは「Claudeがどこまで勝手にやっていいか」の設定です。

最初は **Manual** からでいいです。毎回止まるのは正直めんどくさいんだけど、「何をされてるか」が見えるので、慣れるまではここ。

慣れてきたらこの流れがおすすめです。

1. **Plan** で計画を出させる
2. 中身を確認する
3. **Accept edits** に切り替えて実行する

いきなり書かせるより、先に「何をするつもりか」を言わせた方が事故らないです。

**Bypass permissions** は、意味が分かるまで触らなくていいです！

# Claude Codeを入れたばかりの人へ

## 避けたい4つのこと

- いきなり「〇〇を作って」と丸投げする（先に、何をしてほしいかを書く）
- とりあえず全部「許可」を押す（中身を読んでから押す）
- 毎回ゼロから自分のことを説明する
- 1つの会話を延々と続ける

## 見落としやすい2つ

### ① 毎回ゼロから説明しない

Claude Codeは、新しく始めると前の会話を覚えていません。
自分のこと・作りたいもの・守ってほしい決まりは `CLAUDE.md` に書いておきます。
最初に `/init` と打つと、たたき台を作ってくれます。

### ② 1つの会話で全部やらない

話が長くなるほど、最初に伝えたことが効きにくくなります。
1つ終わったら `/clear` で会話をリセットします。

- 大事なことは `CLAUDE.md` に書いてあるので、リセットしても困りません。
- 「さっきと言ってることが違う」が起きたら、会話が長すぎる合図です。
- 話題が変わるときも、いったんリセットしてから始めるとすっきりします。

## 作る前に「計画モード」にする

パソコンなら、Shift＋Tab を2回押すと切り替わります。
画面の下に今のモードが出るので、切り替わったか見てから頼みます。
アプリ版は、入力欄の近くのメニューから選べます。

頼み方の例：

> まだ作らんで。手順だけ出して

1. 出てきた計画を読む
2. 直したいところを伝える
3. OKなら、作ってもらう

いきなり作らせるより、作り直しがぐっと減ります。

## まとめ

丸投げ・全部許可・毎回ゼロから説明・長すぎる会話、の4つを避けるだけで、ぐっと使いやすくなります。
そのうえで、作る前に計画モードで手順を出してもらいましょう。

1つだけやるなら、次に何か頼むとき、Shift＋Tab を2回押して「まだ作らんで。手順だけ出して」と送ってみてください。
